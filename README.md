# MatchLog Legal

This repository hosts the public legal pages for MatchLog using GitHub Pages.

## Suggested GitHub Pages URLs

Once GitHub Pages is enabled for the `main` branch root, the pages will be available at:

- `https://erndmrcn.github.io/matchlog-legal/`
- `https://erndmrcn.github.io/matchlog-legal/privacy/`
- `https://erndmrcn.github.io/matchlog-legal/terms/`

These URLs are suitable for App Store privacy policy and terms of use links.

## Files

- `index.html`: landing page with links to the legal documents
- `privacy/index.html`: MatchLog Privacy Policy
- `terms/index.html`: MatchLog Terms of Use
- `assets/site.css`: shared styles for all pages

## GitHub Pages Setup

1. Push this repository to GitHub.
2. Open repository `Settings`.
3. Go to `Pages`.
4. Set the source to `Deploy from a branch`.
5. Select branch `main` and folder `/ (root)`.
6. Save.

GitHub will then publish the site automatically.
